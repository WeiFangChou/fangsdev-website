Create a premium, modern corporate website inspired by the visual direction of siwacap.com, but do not copy its exact layout, branding, text, images, or assets.

The website should combine:

- High-end editorial corporate design
- Luxury minimalism
- Strong typography
- Generous whitespace
- Asymmetrical Swiss-inspired grid layouts
- Cinematic transitions
- iOS 26-inspired Liquid Glass visual effects
- Subtle fluid motion and responsive micro-interactions

The result should feel sophisticated, confident, innovative, and timeless — suitable for a premium software development company, technology consultancy, investment company, or modern digital studio.

## Overall Visual Direction

Create a refined visual identity that feels like a combination of:

- Premium private equity website
- High-end architecture studio
- Modern software engineering company
- Apple-inspired product experience
- Editorial business magazine
- iOS 26 Liquid Glass interface

Avoid the typical generic SaaS appearance.

Do not use:

- Bright startup gradients
- Excessive neon colors
- Cartoon illustrations
- Generic dashboard screenshots
- Overused blue-purple SaaS styling
- Heavy drop shadows
- Excessive rounded cards
- Cluttered layouts
- Too many icons
- Cheap glassmorphism

The website should feel calm, spacious, expensive, technically advanced, and highly intentional.

## Color Palette

Use a restrained neutral palette:

- Warm off-white: #F4F1EA
- Soft ivory: #FAF9F6
- Deep charcoal: #111111
- Near black: #080808
- Muted graphite: #2B2B2B
- Warm gray: #A29E95
- Subtle champagne accent: #BFA77A

Use accent colors sparingly.

The primary design should rely on contrast, typography, transparency, reflections, depth, and whitespace rather than colorful decoration.

Support both light and dark sections.

## Typography

Typography should be one of the strongest visual elements.

Use:

- Large editorial headlines
- Elegant modern sans-serif typography
- Optional refined serif typography for selected words or statements
- Tight line-height for hero headings
- Comfortable line-height for body content
- Strong contrast between display text and supporting content

Suggested typography direction:

- Display font: Geist, Inter Tight, Neue Montreal, Manrope, or a similar modern grotesk font
- Editorial accent font: Instrument Serif, DM Serif Display, or a similar elegant serif
- Body font: Inter, Geist, or Manrope

Hero headings should be extremely large and responsive.

Desktop heading size:

- 88px to 144px
- Line-height approximately 0.9 to 1.05
- Slightly negative letter spacing

Mobile heading size:

- 48px to 68px
- Maintain strong visual impact without causing overflow

Use short, confident sentences instead of long marketing paragraphs.

## Liquid Glass Design System

Implement a sophisticated Liquid Glass design language inspired by iOS 26.

Glass surfaces should feel like real optical material, not simple transparent cards.

Each important glass component may include:

- Semi-transparent background
- Backdrop blur
- Background saturation
- Soft inner highlights
- Thin translucent borders
- Directional light reflection
- Subtle refraction
- Slight color dispersion
- Dynamic highlights that respond to pointer movement
- Layered depth
- Soft ambient shadow
- Very subtle noise texture
- Edge lighting
- Smooth morphing transitions

Example visual behavior:

- Glass navigation reflects the content behind it
- Buttons create a soft liquid highlight when hovered
- Cards slightly deform or shift based on cursor position
- Highlights move across the glass surface
- Glass elements become more opaque when content behind them becomes visually busy
- Active navigation items appear embedded inside a liquid glass capsule
- Hovered items slightly magnify as if viewed through curved glass

Do not make every section glass.

Use glass selectively for:

- Floating navigation
- Primary CTA buttons
- Project cards
- Service navigation controls
- Statistics panels
- Image captions
- Contact panels
- Floating labels
- Mobile navigation
- Interactive overlays

Large page backgrounds should remain clean, editorial, and minimal.

## Glass Material CSS Direction

Use a layered glass composition similar to:

- backdrop-filter: blur(20px) saturate(140%)
- translucent white or black background
- 1px semi-transparent border
- inset highlights
- soft external shadow
- pseudo-elements for reflections
- radial gradient that follows the pointer
- subtle SVG displacement or distortion where performance allows

The glass should work in both light and dark environments.

Maintain readable contrast and accessibility.

Provide a fallback design for browsers that do not support backdrop-filter.

## Layout System

Use a 12-column responsive grid.

Desktop:

- Maximum content width between 1280px and 1480px
- Spacious horizontal margins
- Strong alignment between text, images, and section labels
- Asymmetrical compositions
- Large section spacing between 140px and 240px

Tablet:

- Simplified 6-column layout
- Preserve editorial rhythm

Mobile:

- Single-column layout
- Minimum 20px horizontal padding
- Glass elements should remain readable
- Avoid overly complex scroll animations
- Maintain large typography and whitespace

Avoid placing all content inside identical cards.

Let typography, imagery, grid alignment, and empty space define the visual hierarchy.

## Navigation

Create a floating Liquid Glass navigation bar.

Desktop navigation:

- Floating near the top of the viewport
- Rounded but not excessively pill-shaped
- Transparent glass surface
- Brand logo or wordmark on the left
- Navigation links in the center or right
- Primary contact CTA
- Dynamic transparency based on scroll position
- Smooth hide and reveal behavior while scrolling
- Active navigation indicator using a moving liquid capsule

Suggested menu items:

- About
- Expertise
- Work
- Insights
- Contact

On hover:

- Text shifts slightly
- Glass highlight follows the pointer
- Active capsule smoothly morphs between links

Mobile navigation:

- Compact glass navigation
- Animated menu button
- Full-screen translucent glass overlay
- Staggered navigation link entrance
- Background content softly blurred and scaled

## Hero Animation

On initial page load:

1. Background fades in
2. Navigation slides downward with a soft spring
3. Eyebrow text reveals
4. Headline reveals line by line using masked vertical motion
5. Supporting paragraph fades upward
6. CTA buttons appear with slight delay
7. Liquid glass object slowly comes into focus
8. Scroll indicator fades in last

The sequence should feel cinematic and controlled.

Avoid overly dramatic bouncing.

Use natural spring physics and premium easing curves.

Suggested easing:

- cubic-bezier(0.16, 1, 0.3, 1)
- smooth spring animation
- duration between 700ms and 1400ms

The design should remain elegant and calm.

## Animation System

Use smooth, premium, performance-conscious animation.

Recommended animation types:

- Masked text reveal
- Fade and translate
- Staggered entrances
- Subtle parallax
- Image clipping reveal
- Crossfade transitions
- Magnetic buttons
- Cursor-reactive glass highlights
- Smooth active-state morphing
- Soft scroll-linked movement
- Element opacity transitions
- Border drawing
- Background color interpolation
- Gentle scale between 1 and 1.03

Avoid:

- Excessive bouncing
- Constant spinning
- Fast autoplay
- Heavy particle effects
- Large cursor trails
- Overly aggressive scroll hijacking
- Animating every element
- Animation that delays access to content

Respect prefers-reduced-motion.

Disable non-essential motion when reduced motion is enabled.

## Custom Cursor

On desktop, optionally implement a minimal custom cursor.

The cursor may:

- Expand over interactive media
- Display “View”
- Display “Explore”
- Create a subtle optical distortion over glass
- Blend with light and dark backgrounds

Do not hide the native cursor unless the custom cursor is fully accessible and reliable.

Disable the custom cursor on touch devices.

## Scroll Experience

Use native scrolling with smooth animation enhancements.

Do not fully hijack scrolling.

Possible sticky sequences:

- Hero visual remains while text moves
- Project image remains sticky while metadata changes
- Process indicator follows scroll progress
- Section background transitions between light and dark

The scroll experience should feel fluid but predictable.

- RevealText

## LiquidGlass Component Requirements

Create a reusable LiquidGlass component with configurable properties:

- blur intensity
- opacity
- border opacity
- saturation
- shadow strength
- corner radius
- interactive highlight
- dark or light material
- refraction intensity
- hover behavior

The component should support:

- Static glass
- Interactive glass
- Navigation glass
- Button glass
- Card glass
- Overlay glass

Use pseudo-elements for reflections and edge highlights.

Use CSS variables to control pointer-based highlight positions.

Update pointer coordinates efficiently using requestAnimationFrame.

## Performance Requirements

Maintain excellent performance.

Requirements:

- Avoid excessive backdrop-filter layers
- Limit the number of continuously animated elements
- Use transform and opacity for most animations
- Avoid expensive layout animations
- Lazy-load below-the-fold media
- Compress images
- Use responsive image sizing
- Pause animations when elements are outside the viewport
- Avoid large JavaScript bundles
- Avoid unnecessary client-side rendering
- Ensure animations remain smooth on mid-range mobile devices

Target:

- Lighthouse Performance score above 90
- No significant layout shift
- Accessible keyboard navigation
- WCAG AA text contrast
- Responsive design from 320px upward

## Accessibility

Ensure:

- Semantic HTML
- Proper heading hierarchy
- Visible keyboard focus
- Sufficient contrast behind glass surfaces
- Descriptive alt text
- Form labels
- Accessible navigation
- Reduced motion support
- Touch-friendly controls
- No important information communicated only through animation
